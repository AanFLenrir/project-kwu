# KAIROS Design System

## 1. Identitas Visual & Filosofi
KAIROS menggunakan pendekatan visual yang elegan, terpercaya, dan berorientasi produktivitas akademik (*Academic Productivity*).

## 2. Palet Warna (Color Palette)

| Nama Token | Hex Code | Penggunaan |
|---|---|---|
| **Midnight Navy** | `#171747` | Background Sidebar desktop, header hero, typography utama |
| **Deep Navy** | `#211B70` | Gradient panel samping, aksen pembatas sekunder |
| **Royal Indigo** | `#302A91` | Primary action button, menu aktif, link utama, badge |
| **Soft Indigo** | `#EAE9FA` | Background badge kategori, chip tombol, highlight aktif |
| **Champagne Gold** | `#D9B65D` | Ikon aksen emas, border sertifikat, kartu prestasi |
| **Warm Gold** | `#E8C76A` | Gradient tombol sekunder, progress bar emas, lencana |
| **Light Background** | `#F7F7FC` | Background aplikasi keseluruhan (nyaman di mata) |
| **White** | `#FFFFFF` | Background cards, dialog box, surface elevated |

## 3. Tipografi
- **Heading**: `Plus Jakarta Sans`, sans-serif (Tegas, modern, proporsional)
- **Body Text**: `Inter`, sans-serif (Tingkat keterbacaan tinggi pada mobile & desktop)
- **Numerik / ID**: `Spline Sans Mono`, monospace (ID sertifikat, IPK, tanggal, jam)

## 4. Layout Breakpoints (Desktop-First)
- **Desktop (1440 × 900 px & 1366 × 768 px)**: Sidebar navigasi persisten di sisi kiri (256px), area kerja utama lebar multi-kolom grid.
- **Tablet (768 × 1024 px)**: Sidebar adaptif, grid 2 kolom proporsional.
- **Mobile (390 × 844 px)**: Sidebar disembunyikan, digantikan Bottom Navigation 5 tab dengan padding area aman (`pb-safe`).
